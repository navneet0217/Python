### 🔤 Chapter 2 — Python Strings
📁 **Directory:** [`CHAPTER 2 — Python Strings`](CHAPTER%202%20—%20Python%20Strings)

#### 🎯 Key Concepts Covered:
1. **Types & Conversion:** `type()`, `str()`, `int()` with validation.
2. **Math Operations:** `len()`, `count()` on strings.
3. **Transformations:** `replace()`, concatenation (`+`), repetition (`*`), f-strings, `split()`.
4. **Extraction:** Indexing (`[0]`, `[-1]`), Slicing (`[start:stop:step]`), string reversal (`[::-1]`).

6. **Searching:** `in`, `startswith()`, `endswith()`, `find()`.
7. **Validation:** `isalpha()`, `isnumeric()`, `isalnum()`, `isspace()`.
8. **Practical Exercise:** Dynamic string parsing and cleaning (CSV data extraction).
